# CareCompanion — Personal Health & Medication Management Application

> **Purpose:** A simple, accessible personal health management application designed with exceptional design taste and warmth to help people—especially older adults—organize health information, keep track of medications and supplements, remember appointments, and prepare for conversations with healthcare professionals.

---

## 🌟 Key Features

### 1. Senior-Centric Accessible Design & Taste System
- **Adjustable Text Size:** Instant toggle between Regular (16px), Large (18.5px), and Extra Large (21px) across the entire application.
- **High-Contrast WCAG AAA Mode:** Bold borders and high-legibility dark/yellow contrast for visual impairments.
- **Simple / Easy Focus Mode:** A distraction-free 3-step dashboard for days when less is more ("Next Medicine Due", "Drink Water", "Next Doctor Visit").
- **Read-Aloud Voice Assistant:** Browser Web Speech API synthesizer reads medication directions, appointment reminders, and document summaries out loud.
- **Web Audio Chime Simulator:** Gentle melodic chime notifications for scheduled doses.
- **One-Touch Emergency SOS:** Instant access to 911, primary doctor direct dialing, emergency contacts, and vital medical ID for paramedics.

### 2. Core Modules
- **A. Personal Health Dashboard:** Overview of today's doses, next appointment countdown, daily hydration counter, and quick health profile.
- **B. Health Records Organizer:** Manage bloodwork, hospital discharge notes, care plans, and vaccine records in plain language with key findings and target indicators.
- **C. Medication & Supplement List:** Unified list of prescriptions, OTC, vitamins, and supplements with food instructions, pill shape visualizer, and clinician dosage change logs.
- **D. Daily Reminders & Schedule:** Alarms segmented into Morning, Midday, Evening, and Bedtime with repeat reminder snoozes and caregiver notification settings.
- **E. Doctor Appointments & Preparation:** Schedule visits, review address and transit/parking notes, check off questions to ask, and record post-visit follow-up instructions.
- **F. Wellness & Senior Mobility:** Track water glasses, sleep hours, blood pressure readings, and guided physical therapist mobility routines (sit-to-stand, heel-to-toe balance, ankle pumps).
- **G. AI Health Companion:** Plain-language lab explainer, appointment question generator, and clinical safety controls (clarifying that AI does not replace clinical verification, accompanied by a Pharmacist Consultation Checklist).
- **Pocket Health Summary Sheet:** One-click printable doctor visit sheet (`window.print()`) formatted cleanly for physical consultation.

## 🚀 Running the Application

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Or build and preview production bundle
npm run build
npm run preview
```
Application is running at `http://localhost:3002/`.
